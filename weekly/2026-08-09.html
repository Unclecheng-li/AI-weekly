FrontMCP CVE-2026-67531：MCP 框架沙箱逃逸

📅 8月5日 · 来源：Tenable / GitHub Advisory

FrontMCP（TypeScript MCP 框架）披露 CVE-2026-67531，CVSS 9.9（v3）/ 9.3（v4）。其沙箱 codecall:execute 把 host 的 Zod schema 实例暴露给脚本，利用 Proxy 不变量可直达 Function constructor 执行任意代码（仅一次 tools/call 即 RCE）。框架 DEFAULT_AUTH_OPTIONS 为 public 模式，未配置即在无认证下暴露，修复于 1.5.7。这是继 RufRoot（CVE-10.0）后 MCP 攻击面从「语义层」扩展到「框架层」的实锤。

Island 扫描：49% MCP 构建物触发安全规则

8月初 Island 对 33,563 个 MCP 服务器构建物、475,865 个工具做静态扫描：49% 至少触发一条非信息性安全规则，40.6% 含敏感数据访问/代码执行/破坏性操作工具能力。Hacker News 与多家安全机构集中讨论——MCP 安全已是系统性、生态级风险。MCP 安全红队成刚需。
