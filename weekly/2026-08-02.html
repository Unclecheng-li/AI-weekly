RufRoot 引爆 MCP 安全危机
一个未授权请求拿下 AI 全家桶

7月29日，Noma Security 披露 CVE-2026-59726（代号 RufRoot），CVSS 10.0（满分）。开源 AI Agent 编排平台 Ruflo（约 6.7 万 GitHub Star、近千万下载）默认将核心 MCP Bridge 以无认证方式暴露在网络上，桥上挂了 233 个工具（含命令执行、数据库、记忆存储）。攻击者只需一个未认证 HTTP POST，即可在容器内拿到 RCE、窃取 LLM API Key、读取全部用户对话，并向 AgentDB 持久记忆写入恶意指令——让攻击者控制的 Agent 集群以平台合法凭据长期运行。同日 Wiz Research 披露：约 5% 的云环境已暴露公网可达的 MCP 服务器，含财富 500 强泄露 PII。

AI 记忆投毒：补丁不解毒

📅 本周发酵 · 来源：CSO Online / Noma

RufRoot 最具持久性的一击是向 AgentDB 持久记忆写入恶意 pattern：即使原始入侵结束，未来所有用户得到的 Agent 响应都会被污染。Noma 强调处置不能只打补丁——须轮换 LLM API Key、审计 AgentDB 是否被植入、从干净镜像重建容器。把"可写持久记忆"当作安全边界，是绝大多数平台还没做的事。
