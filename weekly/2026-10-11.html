Gemini agent：把「选模型」这件事交给 Agent

📅 10月8日 · 来源：Google 官方博客/Computerworld

Coworker Agent 有了企业身份

同事代理拥有自己的 @agents.company.com 邮箱、日历、Drive 与目录条目，只看到被明确分享的数据。每个 Agent 都有加密证明的身份、OAuth 传播权限、行动级审计轨迹（归属 Agent 而非人）、Agent Sandbox 与 Agent Gateway（Google 称「AI 网络防火墙」）。Google 明确表示不打算按席位收费。
